# Loose screens: evidence

This folder is NOT a gallery of the game (that is what `../starts/` and `../tracks/` are for). It
keeps **evidence** backing a conclusion.

| File | What it is | What it shows |
|------|------------|---------------|
| `attract_python.png` | Four attract screens reproduced in Python from the blits captured at those frames. | That the blit model rebuilds each screen's composition. The globe's colours are not the ones MAME shows on the same screen (golden `goldens/radendurv2/03_boot_15s.png`), so it does not back that screen's palette. |
