# The 16 sections rendered from the ROM (without MAME)

These images are generated by `scripts/radendur-sections-broken.py`, reading the ROM and emulating
the blitter in Python. **The emulator takes no part**, so they answer a question MAME's captures
cannot answer on their own: when a section cannot be played, is it because its DATA is unfinished,
or because the emulation fails?

`radendur_tracks_all.py` renders only the five playable sections (0, 1, 2, 4 and 8) as maps; this
script renders all sixteen, omitting the out-of-range entries and counting how many there were.

## What it proves, and what it does NOT

**It proves** that the sections with a large share of impossible coordinates hold no playable
track: it is not that MAME cannot draw them, it is that what is in the ROM are fragments. The
drawing shows it with no emulator in the way.

**Section 13 is a different case.** Its layout is **continuous and coherent** (no garbage); what it
lacks is ALL the scenery: a level with the road laid and left undressed, a different development
stage from corrupt data.

**It does NOT prove** that those sections hanging is the data's fault alone. The Python render
draws the fragments without dying; a real board might have painted that garbage rather than killing
itself. What is settled is that there is no track there to play.

**The garbage share is NOT the playability criterion.** Section 13 has no garbage and a complete,
continuous layout, and still it is not one of the five that get played through, because it has no
scenery; section 5, the other way round, is half garbage and hangs. "It is unfinished" and "it
cannot be played" are two independent axes: this document reads the ROM data alone, and
[`../starts/README.md`](../starts/README.md) runs each section in the emulator.

## Regenerating

Every image here is versioned; only `../tracks/full/`, the full-resolution renders, is not. They
regenerate from the `radendur` romset in `run/mame_roms/` with:

```sh
uv run scripts/radendur_tracks_all.py
uv run scripts/radendur-track-details.py
uv run scripts/radendur-sections-broken.py
```
